# Mój pierwszy agent — karta obserwacji

- Narzędzie i model:
    Cursor Grok 4.6 Medium
  
- Moje zadanie (2–3 zdania):
    stoper z przyciskami start i stop,
    licznik kliknięć z przyciskiem zerowania,
    quiz z trzema pytaniami i wynikiem na końcu,
    generator haseł z wyborem długości.
  
- Pierwsza wiadomość (wklejona co do znaku):
    Stwórz nowoczesny stoper internetowy z dynamiczną zmianą kolorów co 10 sekund, obsługą okrążeń i responsywnym interfejsem.
  
- Co agent zrobił najpierw:
    Wygenerował strukturę projektu składającą się z plików index.html, style.css oraz app.js oraz przygotował interfejs użytkownika stopera.
  
- O co pytał — i co zostało zatwierdzone bez czytania:
    Agent prawdopodobnie nie wymagał wielu dodatkowych pytań. Automatycznie przyjął funkcjonalności takie jak zmiana kolorów, dźwięki, liczenie okrążeń i skróty klawiszowe.

- Pierwszy błąd i co agent z nim zrobił:
    Nie widać błędów w samym kodzie.
  
- Stan po 25 minutach:
    działa
  
- Skąd wiem, że aplikacja działa (co zostało sprawdzone): 
    przycisk Start uruchamia stoper,
    przycisk Stop zatrzymuje odmierzanie czasu,
    przycisk Reset zeruje licznik,
    przycisk Okrążenie zapisuje międzyczasy,
    licznik zmienia kolory co 10 sekund,
    działa pasek postępu do następnej zmiany koloru,
    działają skróty klawiszowe Spacja, L i R,
    wyświetlana jest lista okrążeń wraz z czasami.
  
- Rzeczy, które agent zrobił, a których nie rozumiem:
    większość rozumiem
  
- Jak mi się wydawało, że poszło (jedno zdanie):
    Agent szybko wygenerował kompletną i estetyczną aplikację, która działa zgodnie z założeniami i wymagała jedynie uruchomienia oraz przetestowania.
